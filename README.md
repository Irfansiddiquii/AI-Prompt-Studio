# 🚀 AI Prompt Studio

AI Prompt Studio is a modern web-based application designed to help users create, organize, manage, and optimize AI prompts efficiently. The platform provides a clean and intuitive user interface that enhances productivity for developers, content creators, students, and AI enthusiasts.

## 📌 Overview

As the use of Artificial Intelligence continues to grow, creating effective prompts has become an essential skill. AI Prompt Studio simplifies the prompt engineering process by providing a dedicated workspace where users can write, edit, store, and manage prompts in an organized manner.

This project focuses on delivering a responsive and user-friendly experience while demonstrating modern front-end development practices.

## 💻 Installation

1. Clone the repository

```bash
git clone https://github.com/Irfansiddiquii/AI-Prompt-Studio.git
```

2. Open the project folder

```bash
cd AI-Prompt-Studio
```

3. Run `index.html` in your browser.
